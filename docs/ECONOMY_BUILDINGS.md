# PIXEL BASTION — 경제 시설과 일꾼 할당 규칙

> 상태: v0.3.8 경제 건물 3×2 설치 및 전역 일꾼 수 관리 적용. 2026-11-13
> 민심 효과 및 업그레이드는 잠금 상태 유지.

## 1. 건물과 타워의 관계

'타워'는 공격 시설에 한정하지 않고 맵에 건설·선택하는 건물 전체를 뜻한다.

- 방어 타워: 기존 화살/대포/빙결/화염 등
- 주거 타워: 초가집 (3×3칸, 최대 3채, 채당 최대 주민 3명, 시간이 흐르며 입주)
- 경제 타워: 광산, 밭

주택·광산·밭 모두 건물 진화/업그레이드 대상이지만 **업그레이드 기능은 잠금**. 광산·밭은 건설·할당·생산 1차 시스템을 구현했다.

## 2. 광산

- 광산 선택 시 **일꾼 할당 / 할당 해제 / 🔒 업그레이드** 버튼 표시.
- 일꾼 할당 대상: 미할당 일반 주민.
- 일꾼이 광산에 배치되면 광부로 직업을 전환.
- 광부는 광산까지 이동해 **광산 입장 애니메이션**을 수행하고 내부로 들어감.
- 내부에 들어간 광부는 할당 해제 전까지 **맵에서 보이지 않고 광산 밖으로 나오지 않음**.
- 광산에 배치된 일꾼 수에 **비례하여 골드 생산**.
- 할당 해제 시 주민이 다시 밖으로 나오게 할 계획. 퇴장 애니메이션/자리/복귀 절차는 미확정.
- **1레벨 광산의 최대 일꾼 수: 1명 (확정).** 1명 배정 중에는 추가 배정 불가.
- 10초마다 일꾼 1명당 골드 +5. 건설 비용은 임시 무료이며 업그레이드별 고용 한도는 미정.

## 3. 밭

- 밭 선택 시 **일꾼 할당 / 할당 해제 / 🔒 업그레이드** 버튼 표시.
- 주민을 일꾼으로 할당/해제할 수 있다.
- **1레벨 밭의 최대 일꾼 수: 1명 (확정).** 1명 배정 중에는 추가 배정 불가.
- 광산과 동일한 일꾼 배정 구조를 사용한다는 것까지 확정.
- 밭 일꾼은 밭까지 걸어가서 일하며 10초마다 1명당 식량 +10. 별도 농부 외형·세부 모션은 미정.
- 별도 지시가 있기 전에는 광산의 '내부에 들어가 숨음' 규칙을 밭에 임의로 적용하지 않는다.

## 4. 주민 관리에서 지킬 불변 조건

- 주민 이동은 한 칸당 한 명 (기존 규칙).
- 임시 잠금 중인 주민 감정·대화·인사 등은 새로운 일꾼 기능을 이유로 해제하지 않는다.
- 일꾼으로 할당된 주민은 동시에 다른 건물의 일꾼으로 중복 배정되지 않도록 구현한다.
- 광산에 들어간 주민은 맵 위를 준무작위 이동하지 않는다.
- 직업 전환은 '일반 NPC가 광부가 되는 것'이지 인구 생성이나 삭제가 아님.
- 총인구와 주택 수용량을 일꾼 수만큼 줄이지 않는다.

## 5. 도입 순서

1. 건물별 선택창: 일꾼 할당 / 업그레이드(잠금)
2. 주민 배정 시스템: 미할당 주민 선별, 배정/해제, 중복 방지
3. 건물로 이동 + 입장/퇴장 애니메이션
4. 광산 내부 상주 및 할당 인원 표시
5. 확정된 수치에 따라 골드/식량 생산 연결
6. 업그레이드/건물 진화 시스템 (후속 설계)

기존 `overlays/assets/reserve/`의 원본 광부·광산·밭 이미지를 보존하며 사용한다.

## 7. v0.3.8 변경 규칙 (확정)

- 광산·밭 건설 면적은 **X축 3칸, Y축 2칸**. 초가집은 기존 3×3칸 유지.
- 광산·밭 스프라이트를 기존 144×146에서 **168×172 픽셀로 약 17% 확대**. 실제 점유는 각각 3×2 타일이며 그림의 투영 여백은 별개.
- 일꾼 할당 창에 **현재 미할당 주민 수** 표시. 감정 표현 등 잠금은 유지.
- 광산·밭에 이미 배정된 모든 일꾼을 총인구에 포함하며, 같은 주민을 중복 배치하지 않음.
- 미할당 주민이 0명인 상태에서 일꾼 할당 버튼을 누르면 **“인구 부족: 배치할 주민이 없습니다.”** 안내.
- 예: 인구 5명 중 광산에 총 4명(여러 광산)이 고용됐다면 1명만 남음. 첫 번째 밭에 1명을 배정한 다음 다른 밭에 1명 추가하려 하면 인구 부족.
- **Lv.1 광산 1개당 최대 1명, Lv.1 밭 1개당 최대 1명** 제한은 그대로 유지. 따라서 Lv.1 밭 한 곳에 동시에 2명 할당하는 기능은 없음.
- 업그레이드는 여전히 잠금, 민심은 식량이 부족해도 변하지 않음.
- 배포 파이프라인에서 `overlays/patch_v038.py`를 v0.3.7 패치 이후 실행한다.


## 8. v0.3.9 표시/일꾼 상태 수정
- 밭 일꾼의 기존 `working` 상태를 **입장 완료 후 `inside` 상태**로 일원화. 광산과 밭 모두 입장 이후 게임 필드·미니맵에 렌더하지 않음.
- 할당 해제 시 해당 주민을 건물 밖 인접 가능한 타일에 복귀시켜 준무작위 이동 재개.
- `econActive`는 일하는 인원을 계산하므로 총인구·식량 소비에 변동 없음.
- 실제 일꾼이 일하는 동안에만 건물 그림을 1~2픽셀 미세하게 움직이고 픽셀 입자를 표시함. 원본 건물 PNG를 변경하지 않음.
- 건물 위에서 건물명, 실제 가동 인원, 10초당 골드/식량 생산량을 상시 확인할 수 있음. 인원이 0명이면 +0으로 표시.
- 생산이 이루어질 때에만 별도의 실시간 상승 숫자(`+골드`/`+식량`)를 잠깐 표시.
- 생산 주기 10초, 광산 +5골드/일꾼, 밭 +10식량/일꾼, 1레벨 최대 일꾼 1명 유지. 업그레이드·민심·NPC 감정 잠금 유지.
- 코드: `overlays/patch_v039.py`를 v0.3.8 패치 다음에 실행.
